# HTML & CSS Challenge Exercises

A collection of HTML and CSS challenge exercises completed while learning and practicing modern web development.

The purpose of this repository is to build a strong foundation in **HTML structure, CSS styling, layouts, responsive design, and general frontend development practices** through hands-on exercises.

## 📚 About

This repository contains solutions to various challenges from my HTML & CSS course.

Instead of only following tutorials, I’m using these exercises to practice writing code from scratch and improve my understanding of how websites are structured and styled.
