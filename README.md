# 🌐 My First HTML Website

This is my very first HTML project. It is a simple webpage created to learn the basics of HTML, including page structure, headings, buttons, and links.

## 📄 Features

- Basic HTML5 document structure
- Webpage title
- Paragraph displaying "Hello, World!"
- A simple button
- A clickable link that opens YouTube in a new tab

## 🛠️ Technologies Used

- HTML5

## 📚 What I Learned

- HTML document structure (`<!DOCTYPE html>`)
- `<html>`, `<head>`, and `<body>` tags
- Creating paragraphs using `<p>`
- Creating buttons using `<button>`
- Creating hyperlinks using `<a>`
- Opening links in a new tab with `target="_blank"`

## 🎯 Future Improvements

- Add headings and images
- Style the page using CSS
- Add JavaScript for interactivity
- Create multiple pages
