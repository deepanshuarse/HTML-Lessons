# ✨ CSS Text Styling Practice

> Learned making plain HTML text look better using CSS.

---

## 🧠 What I Learned

### 🎨 Text & Font Styling

I learned how to control the way text looks:

- `font-family` → changes the font
- `font-size` → changes text size
- `font-weight` → makes text bold
- `color` → changes text color
- `text-align` → controls text alignment
- `line-height` → controls the space between lines

I also learned how to use **Roboto** from Google Fonts.

---

### 📦 Spacing

I practiced controlling space around and inside elements:

- `margin-top`
- `margin-bottom`
- `padding-top`
- `padding-bottom`
